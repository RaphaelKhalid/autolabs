## Architecture

Three deployables share this repo, joined only by HTTP and frozen hashes:

1. **Public site** (`app/`, `components/`, `lib/`) on Vercel at `https://autolabs-ebon.vercel.app`. Server components fetch the Worker through `ORCHESTRATOR_URL` / `NEXT_PUBLIC_ORCHESTRATOR_URL`; the browser never holds provider credentials. `app/api/*` routes are thin proxies to the Worker (status reads) or owner-token-gated control routes (`app/api/control/*`). `lib/experiment-catalog.ts` is the register of experiments; `lib/experiment-landing.ts` decides which experiment the home page shows (a planned successor only replaces the active page once its live status, launch timestamp and protocol hash check out).
2. **Orchestrator Worker** (`orchestrator-worker/`) at `https://autolabs-orchestrator.raphaelbahadurkhan.workers.dev`. `src/index.ts` is the router. It owns the D1 ledger (`migrations/`), idempotency keys, budget/ceiling guards, and all OpenAI calls (`src/openai.ts`, model `gpt-5.6-luna`). Pilot 001 (Erdős 885) runs as a Cloudflare Workflow in `src/workflow.ts`; Experiments 3A/3B are relay-driven shard/claim/score state machines in `src/persona-3a.ts` and `src/persona-3b.ts`. `src/persona-3b-contract.generated.ts` is generated by `research/experiment-003b/scripts/generate_worker_contract.py` and is server-only (it embeds the blind membership hash). Feature flags and the frozen 3B manifest hash live in `wrangler.jsonc` `vars`; secrets live in Wrangler secrets / `.dev.vars`, never in code.
3. **Research pipelines** (`research/experiment-003a`, `research/experiment-003b`). Python scripts validate, blind, relay, and analyze. `autolabs_relay.py` is the only live controller: it authenticates to the Worker, claims shards, and submits payloads; it never calls OpenAI directly and is dry-run by default. `score_luna.py` deliberately refuses `--execute`.

Cross-cutting invariants:

- **Frozen contracts.** Protocol, prompt, schema, manifest and source-artifact hashes are computed per `research/experiment-003b/HASHING.md` (canonical JSON: sorted keys, compact separators, UTF-8; text: LF-normalized). The Worker rejects any start/finalize whose hashes differ. Never edit a frozen threshold, manifest or rubric to make a result pass; record limitations instead.
- **Append-only receipts.** Ledgers, receipts and repair files under `research/**/private-run/` and `private-intake/` are gitignored and must be preserved; supersede a file by copying it to a `-v1` name before replacing it.
- **Budget is enforced server-side.** Each experiment has a hard USD cap and call ceiling in the Worker (3B: $10, original ceiling 1,014, amended effective ceiling 1,400 via `persona_3b_amendments`). Public status must never understate spend or overstate completion.
- **Public pages state what the record supports and nothing more.** No claimed results beyond ledger evidence; zero-candidate or null screens are valid outcomes, not proofs of absence.
